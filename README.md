# WallpaperCat
A cat live wallpaper

# How To Use
- 1. Install Python
- 2. Install requirements `pyautogui` `pywin32` `PyQt5`
- 3. Clone this project
- 4. `cd` to the path to this project
- 5. Execute `python app.py`
